Manual overrides (M9)

Overrides are routed through the same protection gate as automated control (M5) — one that isn't currently safe (e.g. a shed load, or during an islanding/black-start transition) is rejected, visible in the "Manual overrides" decision card above.

Simulation disturbances

Inject environmental/external swings into the running simulation and watch protection/dispatch react — separate from the manual overrides above, which instead dictate a device's setpoint directly.

Device adapters

Every device runs the simulated adapter for now — the real/simulated selector below is wired up and ready, but a real Modbus/SunSpec adapter to select isn't implemented yet.
